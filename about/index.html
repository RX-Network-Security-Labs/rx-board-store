infoAbout RX Board Store

Everything you need to know about the store and how it works.

storefrontWhat is RX Board Store?

RX Board Store is the official extension store for RX Board — a privacy-first, plugin-based Android keyboard developed by RX Network Security Labs (RNSL).

A single place where RX Board users can browse and download plugins, language packs, and voice models made by the RNSL team and the community.

folderFile Formats

extension
Plugin.rxpp

Adds new features, themes, or gestures to RX Board.

language
Language Pack.rxlp

Adds a keyboard layout for a new language or script.

mic
Voice Model.lsttm

Offline voice typing model powered by the Vosk engine.

settingsHow It Works

The store is powered by GitHub Pages and Supabase. Files are stored in the GitHub repository. Ratings, reviews, developer accounts, and submissions are managed via Supabase.

Developers sign up, submit through the website, and the RNSL team reviews every submission before it goes live. This keeps the store safe and high quality.

shieldPrivacy

RX Board has no internet permission by design. The store is a separate website — users manually download and install files. Nothing is sent automatically from the app.

businessAbout RNSL

RX Network Security Labs is an independent developer organization focused on privacy-first tools for Android. RX Board is one of their flagship projects.
